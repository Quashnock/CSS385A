## Game synopsis
The game is a western-themed roguelite shoot where players shoot targets to get points and money for upgrades. These upgrades will help players score more points as the game continues, but if the player runs out of money and bullets then the run is over. Depending on how many points the player scores by the end of a run, they gain a currency used to purchase permanent upgrades that carry across runs.

###Objective
The objective is to shoot targets to score as many points as possible and get improve high scores across runs.

####Mechanics
Players are given a limited number of bullets in their gun's cylinder to shoot targets with at the start of a run. Shooting targets gives players money to use on upgrades and special bullets. Special bullets can include lucky shots that have a chance to apply a large multiplier to the target's score, or scatter bullets that break apart and spread before impact. Targets increase in variety, speed, difficulty and point worth as the game continues, so players will need to balance high-scoring bullets with ones that help them hit targets consistently. If money and bullets run out, then the run is over. Depending on the amount of points scored in a run, players receive a different currency that is used to purchase permanent upgrades that carry across runs. Permanent upgrades can include expansions to the gun's capacity and special bullet upgrades that further enhance their abilities.

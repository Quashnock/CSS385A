## Game synopsis, objective, brief description of mechanics
My game is a western themed roguelite shooting gallery game. In each run of the game you shoot targets with a limited number of bullets to get points and 
money to spend on more bullets and upgrades. Some upgrades can include scatter bullets that spread on impact or lucky shots that have a chance to give you a
large amount of points and money when you hit a target. Targets increase in speed and difficulty as the game continues, so you will need to balance high-scoring bullets with ones that help you hit targets consistently. If you run out of money and bullets then the run ends. Depending on how many points you get in a run you receive a different currency that allows you to purchase permanent upgrades that carry across runs. This game requires a mix of good aim, solid strategy, and just the right amount of risk to get the maximum amount of points possible.
